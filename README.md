## 如何更新笔记

1. 打开对应章节的 README.md，点击铅笔图标编辑。
2. 按“学习目标 → 概念 → 公式与条件 → 推导 → 例题 → 易错点”记录。
3. 在页面中点击 Commit changes（提交更改）保存。

手写笔记可以扫描为 PDF 后放入相应章节；图片可放入 assets，并在笔记中使用相对路径引用。
